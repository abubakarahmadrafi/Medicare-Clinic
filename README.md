# 🏥 MediCare Clinic Website

## Project Overview
MediCare is a 5-page medical clinic website built as a semester project.
It allows patients to learn about the clinic's services, view available
doctors, and book appointments online. The website is fully responsive
and works on mobile, tablet, and desktop screens.

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | index.html | Clinic intro, services overview, stats counter, why choose us section |
| Doctors | doctors.html | Doctor profiles with filter by specialty and live search bar |
| Services | services.html | All medical services with Read More toggle feature |
| Appointment | appointment.html | Online appointment booking form with full validation |
| Contact | contact.html | Contact form, clinic information, and Google Maps |

---

## Technologies Used

- **HTML5** — Structure and content of all pages
- **CSS3** — Custom styling, hover effects, animations
- **Bootstrap 5** — Responsive layout, navbar, cards, grid system
- **JavaScript** — All interactive features (no extra libraries)
- **Git and GitHub** — Version control and project hosting

---

## JavaScript Features

1. **Navbar Scroll Effect** — Navbar background turns white when user scrolls down 50px
2. **Stats Counter Animation** — Numbers count up from 0 to target when home page loads
3. **Doctor Filter** — Filter doctor cards by specialty using category buttons
4. **Doctor Search Bar** — Live search that filters cards as user types in real time
5. **Services Read More** — Toggle button shows and hides extra details on service cards
6. **Appointment Form Validation** — Checks all fields and shows error or success messages
7. **Contact Form Validation** — Validates name, email, and message before submission
